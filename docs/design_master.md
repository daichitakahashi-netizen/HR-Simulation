## 1. プロジェクト概要
本アプリケーションは、100名（および追加10名）の社員データをもとに、複雑な評価重みとペナルティ計算を考慮し、全社売上や特定事業部の利益を最大化する人員配置を算出・比較・決定するための経営・人事向けSaaSである。

## 2. アーキテクチャと技術スタック
*   **フロントエンド:** Angular 
*   **UIコンポーネント:** Angular Material (MatSidenav, MatCard, MatTable, MatExpansionPanel, etc.)
*   **状態管理:** RxJS `BehaviorSubject` / Angular Signal を用いた単一ストア (`SimulationStoreService`)
*   **バックエンド / DB:** Firebase Firestore (※セキュリティ要件に基づき、生CSVデータは保存せず、最終決定された「シナリオサマリー」と「理由テキスト」のみを永続化・共有する)
*   **計算エンジン:** ブラウザ側（TypeScript）でのアルゴリズム計算（トークン消費なしの完全無料動作）

## 3. UI/UX・画面構成（段階的開示とレスポンシブ設計）
全体を「レスポンシブ・サイドナビゲーション」で構成し、以下の5画面を提供する。

1.  **① シミュレーション・ダッシュボード (メイン)**
    *   **左カラム:** `MatSelect`による目的選択、`MatSlideToggle`による110名切替、`MatExpansionPanel`による配置理由の折り畳み表示。
    *   **右カラム:** 全社KPIサマリー、採用前後比較、3事業部のステータス（`MatAccordion`で詳細なペナルティ内訳を折り畳み）。
    *   **UX工夫:** 重い計算中は `MatProgressSpinner` を表示し、計算中であることを明示する。
2.  **② 事業部別・配置分析画面**
    *   上部にコンパクトな「能力値合計・ペナルティ」サマリー。
    *   下部に検索・ソート付き `MatTable` を配置。
    *   ★ 各行に「固定（ロック）」用の `MatIcon` トグルを配置し、手動微調整を実現。
3.  **③ 社員データ・CSV管理画面**
    *   ドラッグ＆ドロップ領域と、全社能力の「強み・弱み」統計サマリー。全社員プレビュー機能。
4.  **④ シナリオ比較・意思決定画面**
    *   保存された複数の配置案を横並びのカードで比較。
    *   「決定」ボタンと「理由メモ」入力フィールド (`MatFormField`) を配置。
5.  **⑤ 配置方針・レポート出力画面**
    *   A4一枚に最適化されたエグゼクティブ・サマリー。
    *   `window.print()` と連携したPDF出力機能と、「配置リストCSV」のダウンロード機能 (`MatButton`)。

## 4. 計算エンジンの追加仕様（プロ仕様）
要件定義書の数式に加え、以下の実務ロジックを実装する。
*   **適正人数の動的スケーリング:** 追加採用で全社員数が変動した場合、充足率を計算するための分母（適正人数）を `基準適正人数 * (全社員数 / 100)` で動的に拡張する。
*   **ルールベース理由生成:** LLMを使用せず、計算結果のパラメータ（一番伸びた指標、回避したペナルティ等）に基づく条件分岐で自然な「配置理由テキスト」を自動生成する。

## 5. 段階的MVP 実装ロードマップ（全7フェーズ）
開発の手戻りを防ぐため、以下の順序で実装とテストを行う。

*   **Phase 1: 純粋な計算ロジック（脳）** / UIなしで要件定義の数式関数のみ実装・テスト。
*   **Phase 2: 状態管理とデータ結合（神経）** / `SimulationStoreService` と100名CSVのパース処理。
*   **Phase 3: 最小ダッシュボード（骨格）** / Angular Material導入。画面①の表示枠のみ作成。
*   **Phase 4: インタラクティブ操作（筋肉）** / 目的の切り替え、10名追加トグルの稼働、リアルタイム再計算の実現。
*   **Phase 5: 詳細分析と微調整機能** / 画面②・③の実装、ソート、検索、ロック（固定）機能の追加。
*   **Phase 6: 意思決定フロー** / 画面④の複数シナリオ比較とFirestoreへのサマリー保存機能。
*   **Phase 7: レポート・出力** / 画面⑤のA4印刷レイアウト調整、CSVエクスポート機能、最終制約チェック。
